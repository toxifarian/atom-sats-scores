# Atom Learning || SATs scores

Produces a KS2 SATs-equivalent scaled score (80–120) for every pupil in every SATs subject, built in BigQuery (`atom-analytics-candidates.paul_martin`).

## How to run

Run the files in `sql/` in numerical order. Every file uses `CREATE OR REPLACE` or `MERGE` with deterministic keys, so re-running produces identical results.
